# 基础三缠论课程体系总览

## 一句话摘要

「基础三」是另一套缠论培训课程（区别于摩尔缠论高三体系），共 22 课，覆盖线段画法、中枢、走势分类、买卖点量化、交易模式和选股体系，强调"唯一性"和"违法执行"的量化交易思路。

## 课程特色

与摩尔缠论（53课）的不同点：
- **跳过"笔"**：直接画线段，用 K 线破坏和重叠来判定中枢，避免级别混乱
- **强调"唯一性"**：顶底唯一、线段唯一、走势唯一、买卖点唯一
- **量化优先**：大量量化规则（13K、5K 重叠、3K 组合、独立两K 等）
- **三段交易为核心**：核心交易模式基于三段结构快速滚动
- **辅助工具**：提倡使用均线（5/34/170）、MACD 等辅助工具高效化缠论系统

## 核心量化规则速查

| 规则 | 条件 | 用途 |
|------|------|------|
| 13K | 顶底之间 ≥13根K线 | 线段最小长度 |
| 5K 重叠 | 重叠区域 ≥5根K线 | 线段中枢成立 |
| 3K 组合 | 中间K线为极值（顶≥左右、底≤左右） | 顶底确认 |
| 独立两K | 连续两K完全在中枢外 | 线段必要条件 |
| 9段升级 | 中枢内部达9段 | 中枢升级为更大级别 |
| 转折四条件 | 底部3K → K线破坏 → 实体突破 → 反向破坏 | 转折成立 |

## 课程金句

- "线段的顶和底一旦确定，线段就唯一确定。"
- "中枢只有'震荡、升级、结束'，没有复杂的延伸、扩张、扩展。"
- "买点不是价格高低，而是上涨结构的确认点。"
- "交易的目的是赚钱，一切与实战无关的知识都是累赘。"
- "选股是选上涨结构，买卖点是执行交易模式。"
- "时间成本比什么都重要——三段走完就结束，不参与震荡。"
- "股票本身没有风险，失去风控才是最大的风险。"
