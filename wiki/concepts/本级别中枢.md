# 本级别中枢

## 一句话摘要

"中枢"是缠论的核心构造单元，但基础三和摩尔缠论对"本级别中枢"的定义方式截然不同——基础三用 3 条线段重叠，摩尔缠论用 34 均线重叠。这意味着两套体系从同一个起点（中枢=本级别）走向了不同的落地路径。

---

## 基础三的定义

> 至少三个连续次级别走势类型的重叠部分。

**简化表述**：本级别中枢由至少**三条连续的线段**的重叠构成。

| 属性 | 规则 |
|------|------|
| 线段 = 次级别 | ✅ |
| 中枢 = 本级别 | ✅ |
| 最少段数 | **3 段** |
| 最多段数 | **9 段**（9 段后升级） |
| 段数只计 | 中枢内部的同向中间段：3、5、7、9 |
| 上下轨确定 | 用 **K 线实体**（收盘价/开盘价），不是最高/最低价 |

### 中枢的三大状态

基础三强调中枢只有三种状态，没有复杂的"延伸/扩张/扩展"：

| 状态 | 条件 | 操作 |
|------|------|------|
| **震荡** | 未结束前 | 随它震荡，不参与 |
| **升级** | 内部达到 9 段 | 自动升级为更大级别中枢 |
| **结束** | 出现三买或三卖点 | 中枢宣告结束 |

### 中枢之间的重叠规则

> 两个中枢之间**绝对不允许有任何重叠**。出现重叠 → 属于同一个中枢的震荡。

---

## 摩尔缠论的定义

> 本质走势中枢：以 34 均线为参照，通过 34 均线的波峰波谷重叠来确定。

| 属性 | 规则 |
|------|------|
| 参照物 | **34 均线**（不是线段或 K 线） |
| 构成方式 | 34 均线重叠的三种情况 |
| 中枢唯一取值 | 34 均线波峰波谷选取 |
| 时间优先 + 34 均线反向 | 复杂中枢重组的核心原则 |
| 肉/非肉优先级 | 肉眼可见（肉）优先于非肉 |

---

## 两套体系的核心差异

| 维度 | 基础三 | 摩尔缠论 |
|------|--------|----------|
| **构成材料** | 线段（次级别走势类型） | 34 均线的波峰波谷 |
| **量化工具** | K 线实体 + 段数 | 34 均线值 + 波峰波谷 |
| **唯一性来源** | 时间优先（先成立的中枢优先） | 34 均线反向 + 时间优先 + 肉优先 |
| **升级条件** | 9 段 | 与走势分类和级别相关，非简单段数 |
| **中枢结束** | 三买/三卖 | 三买/三卖（相同） |
| **震荡态度** | 不参与，换股 | 可做 T（结构未坏时） |
| **重叠限制** | 两个中枢绝对不允许重叠 | 相邻中枢通过连接K容许有限重叠 |

---

## ⚠️ 为什么这个差异很重要？

两套体系从同一个理论源头（缠中说禅）出发，但对"中枢"的落地方式做了不同的选择：

- **基础三路径**：线段 → 线段重叠 → 中枢（纯价格行为）
- **摩尔缠论路径**：中枢线 → 34 均线 → 中枢（价格+均线混合）

这意味着：
1. 同一段走势，两套体系可能画出**不同的中枢**（位置、数量、级别都可能不同）
2. 基于中枢的三买/三卖点也会不同
3. **不能混用**：不能用基础三的线段中枢去对接摩尔缠论的买卖点，反之亦然

### 重叠点

两面在以下基础认知上一致：
- 中枢是级别的载体
- 没有中枢就没有走势
- 三买/三卖宣告中枢结束
