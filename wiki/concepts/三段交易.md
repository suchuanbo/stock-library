# 三段交易

## 一句话摘要

三段交易是基础三缠论体系的核心交易模式——利用三段结构快速滚动，不参与中枢震荡，充分利用小资金的时间成本优势。摩尔缠论中没有"三段交易"这个明确命名的模式，但其买卖点体系隐含了类似逻辑。

---

## 核心定义

> 三段走完就结束，不参与震荡。时间成本比什么都重要。

### 结构

```
本级别中枢 + 第三段启动（一买/二买/三买触发）
→ 持仓 3-5 天（5分钟级别趋势 / 30分钟线段）
→ 三段完成 → 结束 → 换下一只
```

### 与趋势交易的切换

```
起手都是三段交易
  → 三段走完后走势结束 → 结束（换下一个）
  → 三段走完后走势不结束，升级为更大级别中枢 → 切换为趋势交易
```

---

## 模式细节

| 要素 | 三段交易（主模式） | 趋势交易（备选） |
|------|-------------------|-------------------|
| **触发** | 本级别中枢 + 第三段 | 三段完成后走势不结束，被迫升级 |
| **持仓** | 3-5 天 | 等待第二个中枢 → 一卖减仓 → 二卖清仓 |
| **退出** | 三段完成即退出 | 一卖减仓 → 二卖清仓 → 三卖被迫止盈 |
| **适用** | 职业/时间充裕者 | 时间有限的投资者 |
| **优势** | 快速滚动，不参与震荡 | 捕获大牛股全程 |

---

## 背后的哲学：时间成本

> 小资金（1000万以内）可以随时买卖，应充分利用灵活性，快速滚动，不要陪跑。

- 每年 200+ 交易日，只参与 **30 分钟级别上涨**（日线线段上涨）
- 不参与下跌或震荡中的小机会
- 作者个人偏好：只跑三段中的**最后一段**（时间成本最短）

---

## 与摩尔缠论体系的对比

摩尔缠论没有显式命名"三段交易"，但以下元素与基础三有交集或差异：

| 维度 | 基础三 | 摩尔缠论 |
|------|--------|----------|
| 交易模式命名 | **三段交易**（显式命名） | 无统一命名，分散在买卖点中 |
| 结构基础 | 本级别中枢（3段线段） | 日线级别线段 / 走势分类 |
| 持仓时长 | 3-5 天（短线优先） | 按级别定（5分钟~30分钟不等） |
| 震荡态度 | **不参与**（核心原则） | 可做 T 降低成本（结构未坏时） |
| 小资金优势 | **明确强调**时间成本 | 提及但非核心 |
| 风控核心 | 一根 K 线止损法 | 总账户 2% + 股数不变 |

### ⚠️ 关键差异

| 差异点 | 基础三 | 摩尔缠论 |
|--------|--------|----------|
| **是否参与震荡** | 坚决不参与，三段走完就走 | 结构未坏时可做 T，不主动离场 |
| **仓位管理** | 基于择时风险（30分钟涨+日线保→重仓） | 基于日线/30分钟级别组合（8~10成到0~2成） |
| **止损方式** | 一根 K 线止损法（跌破前 K 最低价） | 被动卖点（结构破坏）+ 单笔 2% |
